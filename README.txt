Wamda - How to install

1) Upload all the files in this folder (not the folder itself) to a new GitHub repository.
2) Go to Settings > Pages > Branch: main > Save. Wait a minute until the link appears.
3) Open the link in Chrome on your phone > tap the menu (three dots) > Install app / Add to Home screen.

To add ideas: only change ideas.js. On GitHub, open the file and click the pencil icon to edit it, or upload the new version in its place.

Cover photos (optional): put a photo inside a folder called covers, named after the book, for example covers/kahneman.jpg. It will appear instead of the drawn cover.

The app downloads updates automatically when you open it while connected to the internet.
