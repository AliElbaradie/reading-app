ومضة — طريقة التثبيت
1) ارفع كل ملفات هذا المجلد (وليس المجلد نفسه) إلى مستودع جديد على GitHub.
2) Settings ← Pages ← Branch: main ← Save. انتظر دقيقة حتى يظهر الرابط.
3) افتح الرابط في Chrome على هاتفك ← ⋮ ← تثبيت التطبيق / إضافة إلى الشاشة الرئيسية.
لإضافة أفكار: عدّل ideas.js فقط (من GitHub اضغط على الملف ثم أيقونة القلم)، أو استبدله بالنسخة الجديدة.
التطبيق يجلب التحديث تلقائيًا عند فتحه وأنت متصل بالإنترنت.
